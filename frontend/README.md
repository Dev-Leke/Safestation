# SafeStation AI — Frontend (React Dashboard)

Abimbola's primary area. React dashboard for monitoring incidents.

## Setup
```bash
cd frontend
npm install
npm start
```

## Features needed
- Live incident list from /api/incidents
- Incident detail view with sensor data
- Human review form (approve/reject with notes)
- Telemetry chart showing recent readings
- Status indicator showing system health

## API Base URL
Development: http://localhost:5000
Production: Azure App Service URL
